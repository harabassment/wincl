Чисто · CleanPC 1.0 — Windows 11 x64

ЗАПУСК
Распакуйте архив и дважды нажмите CleanPC.exe.
Установка, Python, PowerShell и права администратора не требуются.
Сборка не подписана цифровым сертификатом.

КАК ПОЛЬЗОВАТЬСЯ
1. Нажмите «Проверить систему». Поиск ничего не удаляет.
2. Выберите строку: внизу появятся полный путь и причина обнаружения.
3. Через «Показать папку» или двойной щелчок проверьте содержимое.
4. Отметьте только ненужные объекты. Галочки автоматически не ставятся.
5. Нажмите «В корзину» и подтвердите операцию.
6. При необходимости откройте корзину и восстановите объекты средствами Windows.
Место на диске освобождается после очистки корзины. Не очищайте её сразу,
если хотите проверить работу приложений после уборки.

ЧТО ИЩЕТ
• Отдельные файлы в %LOCALAPPDATA%\Temp, созданные и изменённые более 7 дней назад.
• Папки первого уровня в Local AppData, Roaming AppData и ProgramData:
  без новых/изменённых объектов за 30 дней, без совпадения имени с названиями
  и издателями в списках удаления программ и папками Program Files.
  Дополнительно проверяются пути установки и исполняемых файлов процессов.

ВОЗМОЖНЫЙ ОСТАТОК — НЕ ГАРАНТИРОВАННЫЙ МУСОР
Возраст файла не означает, что он больше не нужен. Папка может принадлежать
portable-программе, игре, Store-приложению, общей библиотеке или содержать
настройки, сохранения и документы. Совпадения имён — лишь эвристика.
Программа не гарантирует ни полноту поиска, ни отсутствие ложных находок.
Список программ не является полным реестром всех существующих приложений.

ЗАЩИТНЫЕ ПРОВЕРКИ
Системные и некоторые общие папки исключены из поиска. Символические ссылки,
junctions, облачные placeholders и недоступные деревья пропускаются.
При неполном чтении списков удаления очистка кандидатов в остатки блокируется.
Перед очисткой повторно проверяются путь, идентификатор объекта, возраст,
размер, количество файлов и последняя запись. Занятые файлы пропускаются.
Работают ограничения обхода: до 300000 объектов за поиск, 50000 внутри одной
папки, 10000 находок. Прерванный или ограниченный поиск явно помечается.
Повторной попытки удалить без корзины при ошибке перемещения нет.
Операция отмены останавливает обработку после текущего объекта.
Эти проверки не дают гарантии при одновременной работе других программ:
перед очисткой закройте связанные приложения.

ОБЛАСТЬ РАБОТЫ
Приложение читает списки удаления в реестре, но не изменяет реестр,
службы, драйверы, установленные программы или Windows Update.
Оно не просматривает содержимое документов и не отправляет данные в сеть.
Program Files используется как дополнительный список имён; его папки не удаляются.
Удаление поддерживается только на локальном диске типа DRIVE_FIXED.
Для прочих дисков и операций, которые Windows не может выполнить, будет ошибка.
Размеры логические: сжатие, hardlinks и особенности файловой системы влияют
на фактическое освобождение места.

ИСКЛЮЧЕНИЯ И ОТЧЁТ
«Не показывать» сохраняет выделенный путь в исключения.
%LOCALAPPDATA%\CleanPC\exclusions.txt — исключения; удалите файл для сброса.
%LOCALAPPDATA%\CleanPC\history.log — журнал очистки и пропусков с путями.
«Сохранить отчёт» экспортирует текущий список в TSV (UTF-8).

ПРОВЕРКА СБОРКИ
Приложение собрано в Windows PE32+ GUI x64 с ресурсами, иконкой и манифестом.
Тесты правил выполнялись в Linux, тесты файловых операций и поиска — через Wine 10.
Проверены блокировки, идентификаторы, ссылки, границы путей, возраст,
исключения и остановка; окно и кнопка поиска запускаются через Wine.
Перемещение в корзину в тестовой Wine-среде не поддержалось: проверено,
что исходный файл остался на месте и удаления без корзины не последовало.
Непосредственно в Windows 11 сборка ещё не проверялась.
